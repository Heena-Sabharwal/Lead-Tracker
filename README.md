# 🔗 Lead Tracker

A simple Chrome extension that helps you save, manage, and revisit important links with ease.

## ✨ Features

- **Save Input:** Save links by entering them manually into the extension.
- **Save Tab:** Quickly save the URL of the currently opened browser tab.
- **Local Storage:** Store saved links locally in the browser so they remain available between sessions.
- **Delete All:** Clear all saved links with a double-click.
- **Simple Interface:** A clean, minimal design for quick and easy access to your links.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Chrome Extensions API
- Browser Local Storage

## 🚀 Installation

1. Clone this repository or download the source code.

   ```bash
   git clone <your-repository-url>
   ```

2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the project folder containing the extension's `manifest.json` file.
6. Pin Lead Tracker to your Chrome toolbar for easy access.

## 📖 How to Use

1. Click the Lead Tracker icon in your Chrome toolbar.
2. Enter a link in the input field and click **SAVE INPUT** to save it.
3. Click **SAVE TAB** to save the URL of your currently active browser tab.
4. Use the saved links in the extension to revisit them whenever needed.
5. Double-click **DELETE ALL** to clear the saved links.
